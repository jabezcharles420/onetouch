# OneTouch

WhatsApp-native room booking for Dragonfly – The Art Hotel (day-use first, night stays next).

**Live demo (open on your phone):** https://jabezcharles420.github.io/onetouch/

The demo is a basic WhatsApp chat screen that uses only features of the official WhatsApp Business Platform:
a WhatsApp Flow (in-chat booking form), reply buttons, WhatsApp Pay order checkout (UPI, India), a location message and an approved template reminder.
The UPI app screen is simulated.

- `demo/index.html`: demo source
- `docs/index.html`: the GitHub Pages copy (source plus a doctype and mobile viewport header)
